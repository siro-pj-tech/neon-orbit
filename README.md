# Neon Orbit 3D: Overdrive

月夜のテーブル上に浮かび上がる立体ホログラム・ゲームボードをイメージした、3D周回リフレックス・アクションゲームです。  
3つのネオン軌道リングを切り替えて敵（サイバー・ウィスプ）をすり抜け、スコアの上昇とともに加速するオーバードライブ領域でハイスコアを目指します。

[▶すぐに遊ぶ](https://siro-pj-tech.github.io/neon-orbit/)

* **対応環境**: スマートフォン（縦長画面最適化） / PCブラウザ（レスポンシブ対応）
* **技術構成**: Three.js (WebGL) + Tailwind CSS + Web Audio API

---

## 🎮 ゲームルールと特徴

### 1. 短押し＆長押しの2アクション操作
* **短押し（タップ / クリック / Spaceキー）**：内・中・外の3つの軌道リングを順番に切り替えます。
* **長押し**：機体前方に**オレンジ色の三連シールド**を展開し、移動速度を **0.9倍** に減速（ブレーキ）してタイミングを微調整できます。

### 2. フェーズシフト（すり抜け無敵）＆アイテムシールド
* **軌道移動の中盤**：レーン間をジャンプ移動している中盤（ホログラムシールド展開中）は無敵状態となり、敵をすり抜けることができます（外周から内周への2段階ジャンプ時も真ん中の敵をすり抜け可能）。
* **黄金のエネルギーコア**：取得すると **+500点** に加え、約1.5秒間の黄金シールド無敵が付与されます。

### 3. スコア連動オーバードライブ（加速＆最大5体増員）
* スコアが上がるにつれて自機の周回速度が **`1.00x` → 最大 `1.50x`** まで滑らかに加速します。
* 1軌道あたりのサイバー・ウィスプ（敵）もスコアに応じて **1体 → 最大5体** まで段階的に増殖します（出現直後の点滅中は安全）。

## ネオンオービットからネオンオービット3Dへ
### 1.ジャイロ・コア（中心のエネルギー球）

* 輝く内側コアとエネルギーシェルを取り囲む3本の異なる角度の細いジャイロリングを構築。
* 普段はそれぞれの軸で高速回転し、レーン（軌道）を切り替える瞬間にリング全体の傾き（ジャイロ軸）がダイナミックに変化＆回転加速して3Dの立体感を際立たせます。

### 2.ローポリ・スペースシップ（プレイヤー自機）

* 進行方向へ鋭く尖ったデルタ翼・コックピット・ツインスラスターを備えた矢じり型ローポリ戦闘機を構築。
* 軌道移動中には移動方向に応じて機体が左右にグッとロール（バンク傾き）し、機体後部からは太く滑らかに減衰するネオンの光の軌跡（リボン・トレイルメッシュ）を引いてスピード感を演出します。

### 3.サイバー・ウィスプ（敵エネミー）

* トゲトゲした鋭角クリスタル状のコアに回転するスパイクを纏わせ、後ろに軌道そのものをなぞる長い光の帯（リボントレイルメッシュ）が連なる彗星・光の精霊デザインへと進化させました。
